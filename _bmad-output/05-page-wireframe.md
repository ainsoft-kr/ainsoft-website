# 05 Page Wireframe

Updated: 2026-03-12

## Home Page Wireframe

### Global Header

- Logo
- Top navigation
- Primary CTA button

Desktop:

- Horizontal navigation
- CTA on the right

Mobile:

- Logo
- CTA
- Menu trigger

## Home Layout

### Section 1. Hero

- Left:
  - Eyebrow
  - Main headline
  - Supporting copy
  - Primary CTA
  - Secondary CTA
- Right:
  - Company summary card
  - Key capability highlights

### Section 2. Trust Strip

- Key customer/partner/capability metrics

### Section 3. About Preview

- Section label
- Company summary
- 3 strength cards

### Section 4. Products

- Section intro
- 3 product cards
- Each card:
  - Product name
  - One-line summary
  - 3 bullet features

### Section 5. Solutions

- Section intro
- 3 use-case cards
- Each card:
  - Target problem
  - Solution description
  - Expected outcome

### Section 6. Contact

- Left:
  - Contact summary
  - Contact channels
- Right:
  - Inquiry form block

### Section 7. Footer

- Company name
- Navigation shortcuts
- Contact info

## Responsive Notes

- Max content width should be constrained for desktop
- Mobile should stack all 2-column sections vertically
- Cards should collapse from 3-column to 1-column on narrow screens
- Navigation should switch from full menu to compact menu below tablet width
